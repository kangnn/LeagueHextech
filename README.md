# LeagueHextech

> 找到那个马上要开的海克斯乱斗房间。

**LeagueHextech**（海克斯乱斗 5v5 房间搜索器）是一个独立的 Electron 工具：连接已登录的英雄联盟客户端，在公开自定义房间列表里持续搜索，只在符合条件时加入，并在房间里守住直到成局。

面向国服（腾讯客户端）：连接参数全自动获取，**不需要手填端口或令牌**。

## 它解决什么问题

- 房间浏览器里 `10钢 / 10刚` 这类房间，在凑齐人之前普遍一直显示 **1/10**，等它显示 5/10 时通常已经进不去了。所以本工具**不把列表人数当加入条件**——先进入房间，再核对真实人数。
- 房主常常一次性把 50 条邀请发满，这类房间从浏览器**任何人都进不去**（客户端返回 `PARTY_INVITE_LIMIT`）。工具会识别并长期跳过。
- 有些房间永远凑不齐。工具守候一小段时间（可配）后自动退出，继续找下一个。

## 功能

- **自动发现客户端连接**：客户端日志 → `lockfile` → 进程命令行，逐级回退；界面右上角显示连接状态与命中的来源，失败时给出每一步的原因。
- **加入前筛选**：地图 12（嚎哭深渊）、10 人房（5v5）、无密码、房间名含关键词。
- **加入后核对**：模式必须是海克斯乱斗（客户端代号 `KIWI`），且邀请额度未被耗尽。
- **守候规则**：邀请记录数达上限（默认 50）且人数不足下限，或人数在停滞超时（默认 30 秒）内一人未增 → 自动退出并继续搜索。人数每增加一个都会重新计时。
- **不碰你自己的房间**：开始搜索前你已在的房间只会被沿用并报告，工具**永不主动退出**你没有让它加入的房间。
- **事件日志**：按事件类型着色（进行中/成功/放弃/失败），房间号、`3/10 人`、邀请数各是独立芯片，最多保留 200 条；日志上方有聚合统计（尝试 / 进入房间 / 放弃 / 跳过 / 失败）。
- **系统托盘**：关闭窗口不退出，搜索继续在后台跑；左键点托盘显示/隐藏，右键菜单可开始/停止/检查更新/退出。再次双击 exe 不会开出第二个实例，而是把已有窗口唤回来。
- **自动更新**（安装版）：启动 20 秒后检查一次，此后每 6 小时一次；有新版本自动下载，下载完成后界面出现「重启并更新」、托盘菜单出现「重启并更新到 vX.Y.Z」。也可以随时点「检查更新」。
- **凭据只留在内存**：`remoting-auth-token` 与 `Authorization` 标头不写入设置、日志或界面。

## 运行

需要 **Node.js 22+** 和一个已登录的英雄联盟客户端：

```powershell
npm install
npm start
```

## 安装版（推荐，可自动更新）

从 [Releases](https://github.com/kangnn/LeagueHextech/releases/latest) 下载 `LeagueHextech-Setup-x.y.z.exe` 运行即可。安装程序会让你选择安装位置，卸载时**不会**删除你的设置与日志。

想自己构建：

```powershell
npm run build:installer
```

产物在 `release\`：`LeagueHextech-Setup-x.y.z.exe` 与 `latest.yml`（`latest.yml` 是应用内自动更新读取的清单，只有正式版会附带）。

## 免安装版

不想安装就用这个：

```powershell
npm run build:portable
```

产物在 `dist\LeagueHextech\`，双击 `LeagueHextech.exe` 即可，约 317 MB（内含 Electron 运行时）。整个文件夹可以直接拷贝给别人，对方**不需要 Node 或 npm**。

> 免安装版**不能自动更新**——它没有安装目录可供替换，点「检查更新」会提示你去发布页下载新版本。
>
> 另外，两种形态的 exe 都**没有代码签名**：exe 的图标与版本信息已经写入（不再是 Electron 默认 logo），但首次运行仍可能遇到 Windows SmartScreen 的「未知发布者」提示，点「更多信息 → 仍要运行」即可。

## 设置

每一项在界面上都有一个 **?**，鼠标放上去会解释含义。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 轮询间隔 | 2000 ms | 多久重新拉取一次房间列表。500ms 反应最快，但客户端在加载对局时可能来不及应答 |
| 人数下限 | 5 | 只看**进入房间后**的真实人数；低于它就算"人数不足"，只再等"停滞超时"那么久 |
| 邀请上限 | 50 | 派对邀请记录上限（客户端固定 50）。达到该值且人数不足下限 → 判定填不满并退出；`0` = 不检查 |
| 停滞超时 | 30 秒 | 低于人数下限时最多等这么久，到点仍未达下限就退出；`0` = **不等待**，一发现低于下限立刻退出 |
| 房间名关键词 | `10刚,10钢` | 逗号分隔，命中任一才尝试；留空 = 不按名字过滤 |

> 旧版本里 `停滞超时` 的 `0` 表示"永远等待"、且默认 180 秒，与本意相反。读取旧设置时会把未改动过的 180 秒一次性迁移为 30 秒，你自己填过的其它值保持不变。

## 工作方式

状态机：`idle → connecting → searching → joining → verifying → joined`

搜索按**轮（sweep）**推进，每轮是完整的"让客户端重扫列表 → 逐个尝试"：

- 单轮最多尝试 20 个房间，每次间隔 0.5 秒；候选多于 20 个时下一轮从断点轮转，尾部不会被饿死。
- 本轮全部尝试失败后清空记录、重新取列表继续，而不是原地等冷却。轮次间隔 3s 起，列表没有新房间时退避到 15s；一旦出现没见过的房间 ID 立刻回到 3s。
- 因邀请额度耗尽或 `PARTY_INVITE_LIMIT` 被放弃的房间会被记住（默认 10 分钟）：只有列表显示它人数真的变多了才会再试，避免"加入 → 退出 → 再加入"的反复横跳。
- 加入成功后进入**守候**：每个轮询间隔复查一次邀请额度与人数停滞。房间消失（对局开始或自己离开）则停止。
- 请求失败按指数退避重试；只有读取（GET）会在超时后自动重发一次，**写请求（加入/离开）永不重试**——超时的加入可能已经生效，重发等于做两次。
- 空闲连接不复用（LCU 会自行关闭空闲 socket，复用已关闭的连接会表现为"卡满超时"）；任何超过 3 秒的请求会在日志里报出方法与耗时。

### 用到的客户端接口

| 用途 | 端点 |
| --- | --- |
| 房间列表 | `GET /lol-lobby/v1/custom-games`（回退 `v2`） |
| 让客户端重扫列表 | `POST /lol-lobby/v1/custom-games/refresh` |
| 加入房间 | `POST /lol-lobby/v2/party/{partyId}/join` |
| 当前房间（含模式与邀请） | `GET /lol-lobby/v2/lobby`（404 = 不在房间中） |
| 离开房间 | `DELETE /lol-lobby/v2/lobby` |

列表响应里**没有模式字段、也没有成员信息**（只有房主昵称），所以"是不是海克斯乱斗""真实人数是多少"只能进房之后才知道——这正是本工具要先加入再核对的原因。

### HTTPS 与证书

LCU 在 `127.0.0.1` 上使用自签名证书，Electron 的 `net.fetch` 会以 `ERR_CERT_AUTHORITY_INVALID` 拒绝它。因此主进程用 `src/lcu-fetch.mjs`（基于 `node:https`），以 Riot 自带证书做**证书固定校验**，且只允许连接 `127.0.0.1` / `localhost`；仅当固定校验失败时才降级为不校验，并在日志中提示。

## 测试

```powershell
npm test
```

三个套件，约 110 项断言，**不需要 Electron、不需要客户端、不需要 npm install 任何东西**：

| 文件 | 覆盖 |
| --- | --- |
| `tests/controller.test.mjs` | 筛选与排序规则、加入后判定、人数下限与停滞规则、邀请额度、`PARTY_INVITE_LIMIT` 冷却、请求重试策略、设置迁移 |
| `tests/renderer.test.mjs` | 用 DOM 替身执行渲染层真实脚本：日志上限与重复合并、各类型配色、房间芯片、聚合统计、连接胶囊四态、更新状态行 |
| `tests/tray.test.mjs` | 解码内嵌托盘图标 PNG 校验像素、exe 图标容器结构、托盘与"关闭缩到托盘"接线、单实例锁、自动更新接线 |

## 项目结构

```
src/
  main.mjs              Electron 主进程：窗口、托盘、更新、IPC、生命周期
  preload.cjs           受限的渲染层桥（不暴露任何凭据）
  lcu-discovery.mjs     自动发现 LCU 连接参数
  lcu-fetch.mjs         证书固定的 LCU HTTP 客户端（超时、重试、慢请求告警）
  lcu-provider.mjs      LCU 接口封装与响应归一化
  eligibility.mjs       纯函数：筛选、排序、加入后判定
  search-controller.mjs 轮询 / 退避 / 加入 / 守候 / 离开状态机
  settings.mjs          非敏感设置持久化与校验
  riot-certificate.mjs  Riot 自签名证书（用于固定校验）
  renderer/index.html   整个界面：布局、样式与事件渲染
  tray-icon.mjs         生成的内嵌托盘图标（base64 PNG）
scripts/
  build-portable.mjs    从 node_modules/electron 组装免安装目录，并用 rcedit 写入图标与版本
  make-tray-icon.mjs    用纯 Node 画托盘图标与 exe 图标（自写 PNG/ICO 编码）
electron-builder.yml    安装包（NSIS）与自动更新的构建配置
tests/                  三个测试套件
pictures/               README 用图、生成的 icon.ico
release/                安装包产物（不入库）
dist/                   免安装产物（不入库）
```

## 已知限制

- 客户端的公开房间列表**上限 100 条**，同一时刻房间更多时多出来的看不到，只能等下一次刷新。
- 列表不含模式与成员信息，无法在加入前判断——这是客户端接口的限制。
- 仅支持 Windows（国服客户端）。
- **exe 尚未代码签名**：图标与版本信息已写入，但首次运行仍可能被 SmartScreen 拦一次（见下）。
